🔮 Next-Token Prediction — how an LLM writes

A large language model does one thing, over and over: given the text so far, it produces a probability for every possible next token (word-piece), picks one, appends it, and repeats. That's it — no plan, just a very good guess of what comes next. The dial that changes its personality is temperature: low makes it pick the likeliest token every time (accurate but repetitive); high flattens the odds so unlikely words sneak in (creative, or unhinged). What's really going on

Just next-token guessing

Everything an LLM says — essays, code, poems — is this loop: predict the next token, sample it, feed it back. Fluency emerges from a model trained on trillions of tokens to make that guess extremely well.

Temperature = creativity dial

It rescales the odds before sampling. T→0 is "greedy": always the top token (deterministic, safe, repetitive). T=1 uses the raw odds. T>1 flattens them, letting rare tokens win — more surprising, but more error-prone.

Sampling, not truth

The model outputs probabilities, then rolls the dice. High temperature is where "hallucinations" thrive: an unlikely-but-not-impossible token gets chosen and the model confidently continues as if it were right.

Context is everything

The distribution depends on all the preceding text. Each new token you accept changes the odds for the next — which is why the same prompt can wander to wildly different places.

This demo uses a tiny hand-built toy model so it runs in your browser with no server — real LLMs have a vocabulary of ~100,000 tokens and billions of parameters computing each distribution. But the core loop, and the temperature knob, are exactly the same ones behind ChatGPT and Claude.
