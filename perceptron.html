🕸️ The Perceptron — a single neuron learns

Every neural network is built from one simple unit: the neuron. It multiplies each input by a weight, adds them up (plus a bias), and fires if the total crosses a threshold. Learning is nothing more than nudging those weights until the neuron gets its answers right. Below, a single neuron tries to separate blue points from red ones by finding the right line. From one neuron to deep learning

Weighted sum + threshold

output = 1 if (w₁x₁ + w₂x₂ + b) > 0, else 0. The weights say how much each input matters; the bias shifts the threshold. That's the entire neuron.

Learning = fixing mistakes

For each wrong answer, nudge the weights toward the right one: w += (target − output) × input. Repeat over the data and the boundary line rotates into place. Guaranteed to work — if a line can separate the classes.

One neuron = one line

A single perceptron can only carve the plane with a straight line. Flip on XOR above: no line can separate it, and training never settles. This limit nearly killed AI research in the 1970s.

Stack them → anything

Layer neurons and feed one's output into the next, and the network can bend boundaries into any shape. That's a deep neural net — trained not by this rule but by gradient descent and backpropagation.

Invented in 1958 by Frank Rosenblatt, the perceptron was hyped as a machine that would "walk, talk, see, and write." The XOR limitation dashed those hopes — until, decades later, multi-layer networks and backpropagation revived the idea and became the deep learning that powers modern AI. Every giant model is, at heart, a vast web of these little units.
